# Notebooks Overview

- [`data_inventory_and_hypotheses.ipynb`](./data_inventory_and_hypotheses.ipynb) - Input audit and initial hypotheses (Q1-Q5 framing).
- [`performance_topology.ipynb`](./performance_topology.ipynb) - Global method comparison, rank views, winner-by-strata, and seed fragility snapshots.
- [`questions_q1_q2_q3.ipynb`](./questions_q1_q2_q3.ipynb) - Focused analysis for contamination sensitivity, dimensional robustness, and correlation effects.
- [`q4_q5_failure_gallery.ipynb`](./q4_q5_failure_gallery.ipynb) - Redundancy (Kendall), elbow parity diagnostics, and failure-oriented topology view.
- [`two_d_datasets_visualizations.ipynb`](./two_d_datasets_visualizations.ipynb) - 2D visual analysis (per-model panels, cross-dataset comparison, all-model score maps).
- [`hyperparameter_stability_deep_dive.ipynb`](./hyperparameter_stability_deep_dive.ipynb) - Hyperparameter sensitivity, seed stability, and per-algorithm parameter importance.
- [`verification_task_report.ipynb`](./verification_task_report.ipynb) - Full verification-task workflow for `test_data.csv` and `test_labels.csv` export rationale.

- [`analysis_helpers.py`](./analysis_helpers.py) - Shared plotting style, loading helpers, and figure annotation/saving utilities.
