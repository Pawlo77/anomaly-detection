# Outputs Catalog and Reproduction

This file documents how each CSV in `outputs/` is produced.

## Pipeline-generated CSVs

- `descriptive_stats.csv`
  - Generated by dataset pipeline stage in `src/anomaly_detection/datasets/pipeline.py`.
  - Command: `make datasets`

- `validation_report.csv`
  - Generated by dataset validation stage in `src/anomaly_detection/datasets/pipeline.py`.
  - Command: `make datasets`

## Orchestration/training-generated CSVs

- `phase4_summary.csv`
  - Exported by `src/anomaly_detection/orchestration/reporting.py`.
  - Command: `make experiments EXPERIMENTS_PHASE=phase4`

- `phase6_elbow_validation.csv`
  - Exported by `src/anomaly_detection/training/phase6_artifacts.py`.
  - Command: `make phase6-artifacts`

## Notebook/report-derived CSVs

- `local_global_taxonomy_summary.csv`
  - Written in `notebooks/questions_q1_q2_q3.ipynb` (`regime_summary.to_csv(...)`).
  - Rebuild:
    - Execute `notebooks/questions_q1_q2_q3.ipynb` from `notebooks/`.

- `quantitative_metric_summary.csv`
  - Report summary artifact (oracle-threshold metric means/stds) consumed by `report/report.tex`.
  - Rebuild path:
    - Start from `phase4_summary.csv`.
    - Re-run report analysis notebook pipeline in `notebooks/performance_topology.ipynb` and save table export.

- `estimated_vs_oracle_threshold_delta.csv`
  - Report summary artifact (estimated-threshold minus oracle-threshold deltas) consumed by `report/report.tex`.
  - Rebuild path:
    - Start from `phase4_summary.csv` + `phase6_elbow_validation.csv`.
    - Re-run report analysis notebook pipeline in `notebooks/performance_topology.ipynb` and save table export.

- `estimated_threshold_absolute_metrics.csv`
  - Derived for report table from:
    - `quantitative_metric_summary.csv` (oracle absolute metrics), and
    - `estimated_vs_oracle_threshold_delta.csv` (estimated-oracle deltas).
  - Rebuild command:
    ```bash
    uv run python - <<'PY'
    import pandas as pd
    oracle = pd.read_csv('outputs/quantitative_metric_summary.csv')
    delta = pd.read_csv('outputs/estimated_vs_oracle_threshold_delta.csv')
    m = oracle.merge(delta, on='algorithm', how='inner')
    for k in ['accuracy', 'precision', 'recall', 'mcc', 'f1']:
        m[f'{k}_estimated_mean'] = m[f'{k}_mean'] + m[f'delta_{k}']
    m['roc_auc_estimated_mean'] = m['roc_auc_mean']
    m['pr_auc_estimated_mean'] = m['pr_auc_mean']
    out = m[['algorithm','accuracy_estimated_mean','precision_estimated_mean',
             'recall_estimated_mean','mcc_estimated_mean','f1_estimated_mean',
             'roc_auc_estimated_mean','pr_auc_estimated_mean']].sort_values('algorithm')
    out.to_csv('outputs/estimated_threshold_absolute_metrics.csv', index=False)
    PY
    ```

- `iforest_pca_ablation_subset.csv`
  - Derived for supplementary report ablation from `phase4_summary.csv`.
  - Rebuild command:
    ```bash
    uv run python - <<'PY'
    import pandas as pd
    s = pd.read_csv('outputs/phase4_summary.csv')
    ifo = s[s.algorithm == 'IForest'].copy()
    subset = ['arrhythmia', 'mnist', 'musk', 'speech']
    eng = ifo[(ifo.variant == 'track-a-defaults') & (ifo.dataset.isin(subset))]
    pca = ifo[(ifo.variant == 'pca-0.99') & (ifo.dataset.isin(subset))]
    rows = []
    for d in subset:
        a = eng[eng.dataset == d]
        b = pca[pca.dataset == d]
        if a.empty or b.empty:
            continue
        rows.append({
            'dataset': d,
            'pr_auc_engineered_mean': a.pr_auc.mean(),
            'pr_auc_pca99_mean': b.pr_auc.mean(),
            'delta_pr_auc_pca99_minus_engineered': b.pr_auc.mean() - a.pr_auc.mean(),
            'roc_auc_engineered_mean': a.roc_auc.mean(),
            'roc_auc_pca99_mean': b.roc_auc.mean(),
            'delta_roc_auc_pca99_minus_engineered': b.roc_auc.mean() - a.roc_auc.mean(),
            'seeds_engineered': a.seed.nunique(),
            'seeds_pca99': b.seed.nunique(),
        })
    out = pd.DataFrame(rows)
    out.loc[len(out)] = {
        'dataset': 'mean_over_subset',
        'pr_auc_engineered_mean': out.pr_auc_engineered_mean.mean(),
        'pr_auc_pca99_mean': out.pr_auc_pca99_mean.mean(),
        'delta_pr_auc_pca99_minus_engineered': out.delta_pr_auc_pca99_minus_engineered.mean(),
        'roc_auc_engineered_mean': out.roc_auc_engineered_mean.mean(),
        'roc_auc_pca99_mean': out.roc_auc_pca99_mean.mean(),
        'delta_roc_auc_pca99_minus_engineered': out.delta_roc_auc_pca99_minus_engineered.mean(),
        'seeds_engineered': int(out.seeds_engineered.min()),
        'seeds_pca99': int(out.seeds_pca99.min()),
    }
    out.to_csv('outputs/iforest_pca_ablation_subset.csv', index=False)
    PY
    ```
